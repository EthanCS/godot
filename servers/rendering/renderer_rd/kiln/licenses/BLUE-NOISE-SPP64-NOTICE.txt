Blue-noise sampling tables from blue-noise-sampler 0.1.0, src/spp64.rs.
Source: https://github.com/Jasper-Bekkers/blue-noise-sampler
Author listed in the crate: Jasper-Bekkers <bekkers@gmail.com>
The published crate Cargo.toml declares license = "MIT".
Tables retained verbatim as bytes in order: SOBOL (65536), RANKING_TILE
(131072), SCRAMBLING_TILE (131072). GLSL reads the same values as Kajiya's
blue_noise_sampler. No random replacement is used.

The crate README attributes the tables to Eric Heitz et al.,
"A Low-Discrepancy Sampler that Distributes Monte Carlo Errors as a Blue Noise in Screen Space".
